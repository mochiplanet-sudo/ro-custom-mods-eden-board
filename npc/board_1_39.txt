// 全域擊殺監聽核心 (自動更新任務計數與跳字提醒，僅限同畫面 20 格內隊友共享)
// ==============================================================
OnNPCKillEvent:
    .@pid = getcharid(1); // 獲取隊伍 ID

    // 情況 A：單人遊玩 (無組隊)，直接結算自己
    if (!.@pid) {
        callsub OnCheckTaskProgress, killedrid;
        end;
    }

    // 情況 B：組隊狀態，共享進度
    .@killedrid = killedrid; // 將魔物ID轉為腳本局部變數保護
    getpartymember .@pid, 1; // 填入 $@partymembercid (角色ID)
    getpartymember .@pid, 2; // 填入 $@partymemberaid (帳號ID)
    getmapxy .@map1$, .@x1, .@y1, UNITTYPE_PC; // 抓取擊殺者的正確座標

    for (.@i = 0; .@i < $@partymembercount; ++.@i) {
        // 精確驗證該隊友角色是否真正處於在線狀態
        if (isloggedin($@partymemberaid[.@i], $@partymembercid[.@i])) {
            attachrid $@partymemberaid[.@i]; // 切換至該隊友
            getmapxy .@map2$, .@x2, .@y2, UNITTYPE_PC;

            // 條件：同地圖 + 存活 + 擊殺者周圍 20 格視野緩衝區內
            if (.@map1$ == .@map2$ && distance(.@x1, .@y1, .@x2, .@y2) <= 20 && Hp > 0) {
                callsub OnCheckTaskProgress, .@killedrid;
            }
        }
    }
    end;
